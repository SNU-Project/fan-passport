# 디지털 팬 여권 (Fan Passport)

> 공연 티켓을 **돈이 아니라, 살 수 없는 화폐로 배분한다.**

암표를 "단속"하는 대신, 암표가 성립할 수 없는 구조를 만드는 스마트컨트랙트 프로토타입입니다.
블록체인 강의 기말 프로젝트 제안서([`docs/제안서.md`](docs/제안서.md))의 아이디어를 실제로 배포·실행되는 코드로 옮긴 것입니다.

---

## 30초 요약

공연에 실제로 **입장**하면 내 지갑에 도장이 하나 찍힙니다. 이 도장은 **남에게 팔 수도, 넘길 수도 없습니다.**
쌓인 도장은 다음 공연 티켓을 받을 때 쓰는 **점수**가 됩니다.

- 티켓은 NFT이지만 **공식 반납 말고는 어디로도 못 보냅니다.** → 웃돈을 받고 넘겨줄 방법 자체가 없습니다.
- 못 가게 되면 **정가 그대로 반납**하고, 반납된 좌석은 다시 점수 경매로 돌아갑니다.
- 암표상은 자본이 아무리 많아도 **이 경매의 지불수단(팬 점수)을 구할 수 없습니다.** 직접 공연에 가는 것 말고는.

## 바로 돌려보기

```bash
npm install && npm run demo
```

인메모리 이더리움(ganache) 위에 계약을 실제로 배포하고, 암표상이 어디서 막히는지를
9막짜리 시나리오로 보여줍니다. 외부 네트워크도 지갑도 API 키도 필요 없습니다.

> `µWS is not compatible with your Node.js build` 경고는 ganache가 네이티브 바이너리 대신
> 순수 JS 구현으로 넘어간다는 안내일 뿐입니다. 시연에는 아무 영향이 없습니다.

### 시연 시나리오

| 막 | 무슨 일이 일어나는가 | 확인하는 것 |
|---|---|---|
| 1 | 팬 6명에게 여권 발급, 과거 참석 이력 부여 | 암표상도 여권은 받지만 점수는 0 |
| 2 | 암표상이 팬 이력 자체를 사려 함 | `Soulbound` — 이력은 시장에 나올 수 없음 |
| 3 | 1차 배정: 우선권 2석(점수 경매) + 일반 2석(추첨) | 부계정 응모 차단, 중복 응모 차단, 신규 팬도 추첨으로 입장 |
| 4 | **암표상이 티켓을 되팔려고 시도** | 직접 전송·마켓 등록·우회 전송 전부 `NonTransferable` |
| 5 | 되팔지 못한 암표상이 공식 반납 | 정가+보증금 전액 환불 → 차익 0 |
| 6 | 반납된 좌석을 다시 점수 경매로 | 암표상은 점수가 0이라 입찰 자체가 불가 |
| 7 | 공연 당일 입장 / 노쇼 | 입장해야만 도장이 찍히고 보증금이 돌아옴 |
| 8 | 1년 경과 | 점수 감가 — 고인물 영구 독점 방지 |
| 9 | 최종 상태 | 암표상의 최종 참석 기록: **0회** |

## 설계의 핵심 5가지

**1. 팬 여권은 팔 수 없다 (소울바운드)**
`transferFrom` / `approve`가 존재하되 **항상 실패**합니다. 구현하지 않은 게 아니라 명시적으로 거부하는 이유는,
지갑이나 마켓플레이스가 사용자에게 "왜 안 되는지"를 보여줄 수 있어야 하기 때문입니다.

**2. 티켓은 반납 말고는 못 움직인다**
`transferFrom(from, to, id)`는 `to`가 계약 자신일 때만 통과합니다. 즉 **모든 이전 경로가 공식 반납 하나로 수렴**합니다.
현금이 오갔더라도 온체인 소유자가 바뀌지 않으므로, 공연장에서 신분증과 대조하면 입장이 거부됩니다.
*사후 적발이 아니라 사전 불가능*이라는 점이 현행 제도와의 결정적 차이입니다.

**3. 좌석은 두 갈래로 나눈다**
- **우선권 트랙**: 팬 점수로 입찰. 입찰한 점수는 낙찰 여부와 무관하게 소모됩니다(올페이 경매).
  전원이 최대치를 지르는 무의미한 경쟁을 막고, "얼마나 간절한가"에 실제 비용을 붙이기 위해서입니다.
- **일반 트랙**: 점수와 무관한 무작위 추첨.
  점수로만 나누면 신규 팬이 영원히 진입하지 못해 팬덤이 닫혀버립니다.

**4. 노쇼 보증금**
예매 시 소액을 예치하고, **실제 입장하면 전액 환급**합니다. 반납에는 페널티가 없고 무단 노쇼만 몰수됩니다.
빈 좌석을 만드느니 반납하게 만드는 인센티브 설계입니다. 몰수된 보증금은 다음 회차 팬 리워드 재원이 됩니다.

**5. 점수는 시간이 지나면 줄어든다**
출석 점수는 2년에 걸쳐 0으로 선형 감소합니다. 20년 전에 한 번 간 사람이 영원히 1순위가 되는 것을 막습니다.
**중요**: 적립분과 소모분이 *같은 속도로* 감가되어야 합니다. 적립만 감가시키면 시간이 지날수록
차감액이 상대적으로 커져 모든 팬의 점수가 0으로 수렴하는 버그가 생깁니다.

```
  demo.js            9막 시연 (컴파일 → 배포 → 시나리오 실행)
docs/
  제안서.md           제출용 제안서 초안
```

## 솔직한 한계

제안서에도 그대로 적어야 할 부분입니다. 블록체인이 만능이 아니라는 걸 아는 게 더 중요합니다.

- **본인확인은 체인 밖의 일입니다.** "1인 1여권"의 진짜 근거는 오프체인 실명확인이고,
  체인은 그 결과를 위조 불가능하게 기록할 뿐입니다. 신분 위조로 여권을 여러 개 만들면 막을 수 없습니다.
- **입장 검표 단말을 신뢰해야 합니다.** 검표기가 거짓 스탬프를 찍으면 체인은 그대로 받아들입니다(오라클 문제).
- **추첨 난수가 데모용입니다.** `blockhash` 기반이라 채굴자·검증자가 조작할 여지가 있습니다.
  실서비스는 체인링크 VRF나 커밋-리빌 방식이 필요합니다.
- **참석 기록이 공개됩니다.** 지갑 주소만으로도 "누가 어느 공연에 갔는지"가 드러나므로,
  실제로는 해시 커밋이나 영지식증명으로 가려야 합니다.
- **점수 계산이 반복문입니다.** 참석 횟수가 수백 회로 늘면 가스 비용이 커집니다.
  누적합을 저장하는 방식으로 최적화해야 합니다.
